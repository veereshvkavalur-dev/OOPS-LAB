## About This Repository

This repository contains the programs completed for the Object Oriented Programming (OOPS) laboratory using C++. The work is arranged session-wise so that each set of programs can be easily located, compiled, and practiced.

The programs progress from basic C++ concepts to classes, constructors, static members, and inheritance. The implementations are kept simple for laboratory practice and revision.

## How to Run

Compile any program with a C++ compiler, for example:

```bash
g++ filename.cpp -o program
./program
```

On Windows, the generated executable can be run using:

```text
program.exe
```
